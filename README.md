- Este curso está diseñado para aprender a construir **APIs reactivas de alto rendimiento** utilizando

  eficientes.

## 📝 Ejemplo de motivación

Imagina que tu aplicación debe manejar **miles de peticiones concurrentes** (por ejemplo, un sistema bancario o una
plataforma de streaming).

- Con `Spring MVC tradicional`, cada petición consume un hilo, lo que limita la escalabilidad.
- Con `Spring WebFlux`, las peticiones se gestionan de manera **no bloqueante**, permitiendo que un mismo hilo atienda
  múltiples solicitudes.
